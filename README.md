## 📖 About the App

toolsSrg is an all-in-one toolkit for Android. Instead of installing a separate app for every small job, you get 131 tools in one clean, fast interface: generate a QR code, work out a discount, rewrite some text, check a color contrast, or pick a random password.

Everything runs on your device. There are no ads, no sign-up and no tracking, and every tool works without a connection.

## 🔳 QR Studio

Turn almost anything into a QR code and make it look the way you want.

| Type | What it does |
|------|--------------|
| **URL** | Turn a link into a QR code |
| **Text** | Encode any free text |
| **WiFi** | Scan to join a network instantly |
| **WhatsApp** | Open a chat with a number |
| **Email** | Pre-fill an email |
| **Contact** | Save a contact card (vCard) |
| **Location** | Point to coordinates on a map |

**Custom styles:** square, soft, dot, heart, diamond and star modules, three eye styles, six color gradients, four background tones and four error-correction levels.

## 📲 Installation Guide

1. **Download** the APK with the button at the top (or from the [Releases](https://github.com/Abid-developerApK/toolssrg-android-toolkit/releases) page)
2. **Open** the downloaded `toolsSrg-Android.apk` from your notification bar or file manager
3. If Android asks, **allow installing from unknown sources** for your browser or file manager
4. Tap **Install** and wait a few seconds
5. **Open** toolsSrg, pick a category or use the search bar, and tap **Run**

## 🛠️ Troubleshooting

| Problem | Fix |
|---------|-----|
| "App not installed" | Uninstall any older copy first, and make sure you have at least 50 MB free |
| Install is blocked | Settings → allow "Install unknown apps" for your browser or file manager |
| Play Protect warning | Tap **More details** → **Install anyway** (the app is distributed outside the Play Store) |
| QR code will not generate | Shorten the text (about 150 characters is the maximum) |
| Favorites missing | Favorites are stored on the device and are cleared if you clear app data |

## 🧰 Behind the App

toolsSrg is built with web technologies (HTML, CSS and JavaScript) and packaged as a native Android app. The QR encoder is written from scratch inside the app, which is why everything works offline.
